# Security Policy

## Supported Versions

We release patches and security fixes for the active development branch of AI Mentor.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

The AI Mentor team takes security seriously. If you discover a security vulnerability, please report it privately to our team rather than opening a public issue.

### How to Report

1. **Email:** Send details of the vulnerability to the project maintainers or security leads.
2. **Details to include:**
   - A description of the vulnerability and its potential impact.
   - Step-by-step instructions or proof-of-concept to reproduce the issue.
   - Any suggested mitigations or patches.

### What to Expect

- We will acknowledge receipt of your report within 48 hours.
- We will investigate and provide a status update as soon as possible.
- Once a fix is validated, we will release a patch and publish a security advisory if appropriate.

For general contribution guidelines, please refer to [CONTRIBUTING.md](file:///CONTRIBUTING.md).
